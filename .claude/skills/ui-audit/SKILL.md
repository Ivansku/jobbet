# UI Audit Skill

This is an existing app. Do not redesign globally unless explicitly asked.

When reviewing UI in this project:

1. Do not change code unless explicitly asked.
2. Identify existing patterns before recommending new ones.
3. Prefer reuse of existing components.
4. Do not introduce new colors, spacing, typography or component variants unless the existing system cannot support the requirement.
5. Compare similar screens and components.
6. Look for inconsistent spacing, color, typography, border radius, shadows, icons, button variants, form states and layout patterns.
7. Check accessibility risks such as missing labels, weak focus states, poor keyboard flow, contrast issues and unclear error messages.
8. Produce findings grouped by severity.
9. Recommend the smallest safe changes first.
